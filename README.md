# 项目简介

## 核心功能
- 登录注册
- 招聘数据总览
- 数据可视化
- 数据检索
- 职位推荐
- 用户设置
- 爬虫调度
- 用户管理
- 招聘信息管理

## 适用场景
- 招聘信息分析
- 职位推荐服务
- 用户数据管理
- 招聘网站数据挖掘

## 技术特点
- 使用 Django 框架搭建后端
- MySQL 数据库存储招聘数据
- HTML/CSS/JS 进行前端展示
- Echarts 实现数据可视化
- 基于协同过滤算法的职位推荐
